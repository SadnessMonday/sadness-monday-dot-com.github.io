# sadnessmonday.com

Source for [sadnessmonday.com](https://sadnessmonday.com), Sadness Monday Productions' website. Built with [Hugo](https://gohugo.io/) using the Ananke theme, and deployed to GitHub Pages via a GitHub Actions workflow (`.github/workflows/hugo.yaml`) triggered on pushes to `prod`.

Content includes the home/contact pages and blog posts announcing and covering projects such as BetterPhysics and Nomads.

## Tech

- Hugo static site generator (Ananke theme)
- GitHub Actions for build + deploy
- GitHub Pages hosting, custom domain via `CNAME`
